# Employee Analytics Dashboard – Power BI

## Project Overview
This project is an interactive Employee Analytics Dashboard built using Microsoft Power BI. It provides insights into employee demographics, departments, business units, salaries, employee status, and workforce trends.

## Objectives
- Analyze total, active, and departed employees
- Understand employee distribution across departments
- Analyze employees by gender and country
- Compare salaries across business units and countries
- Identify employee trends over time
- Analyze employee distribution by age group
- Provide interactive filtering for deeper analysis

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Dashboard Features

### Key Performance Indicators
- Total Employees: 1,000
- Active Employees: 915
- Departed Employees: 85
- Job Titles: 33
- Total Annual Salary: 129.09M

### Interactive Filters
The dashboard includes slicers for:
- Department
- Gender
- Country
- Job Title
- Business Unit

### Visualizations
- Employee count by department and gender
- Employee count by year
- Salary by business unit and country
- Employee distribution by business unit
- Employee distribution by age group
